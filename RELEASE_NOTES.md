### Full release notes (for website, GitHub, etc.)

We're pleased to announce the first public release of **Chess Tournament Manager**, an Android app for running chess tournaments with Swiss and Round Robin formats, standings, tiebreaks, backup, and optional web publishing.

**Tournament Formats**
- **Swiss System** — FIDE C.04.1 compliant pairings for fair, competitive play
- **Round Robin** — Every player faces every other player once

**Player Management**
- Add and edit players with name, FIDE ID, and rating
- Reuse a shared player pool across tournaments

**Standings & Tiebreaks**
- Live standings, 8 tiebreak systems (Buchholz, Sonneborn-Berger, etc.)
- Configurable tiebreak chain

**Tournament Management**
- Create tournaments, enter results (1–0, 0–1, ½–½)
- View pairings, round details, cross-table
- Text report sharing

**Backup & Restore** — Export and import all data (Pro)

**Web Publishing** — Share tournaments online with a link (Pro)

**Pro & Free** — Free: unlimited players, pairings, results, standings. Pro: backup, web publishing, no tournament limit. First tournaments free for everyone.
